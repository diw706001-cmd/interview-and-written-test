通用 API

            

              
                
方法路径说明

              
              
                
POST/api/v1/dynamic-data/:formId提交表单，按最新发布版校验并入库

                
GET/api/v1/dynamic-data/:formId按 JSON 字段分页、筛选、排序

                
GET/api/v1/forms/:formId/schema读取当前发布版 Schema

                
POST/api/v1/forms/:formId/schema/publish发布新版本

              
            

          

          

            

              
文件上传

              
文件不直接写入 Submission JSON，只存 fileId / storageKey / hash。

            

            

              
扩展机制

              
通过 hook 处理通知、PDF、第三方同步等后置动作。

            

          

        

      


      

        

          

            
版本策略

            

              
已发布 Schema 不可直接修改。

              
改动生成新版本，并保留 parentVersion。

              
历史 Submission 永久绑定旧版本。

              
新 Submission 永远使用最新 Published Version。

            

          

          

            
并发控制

            
保存时带 version / ETag，若版本不一致则拒绝写入，避免 B 覆盖 A。
